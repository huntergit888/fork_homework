Git

  • git init - создает новый локальный репозиторий в текущей папке (инициализирует пустую базу).
  • git clone - создает локальную копию удаленного репозитория.
  • git status - показывает состояние рабочего каталога: какие файлы изменены, какие добавлены в индекс (готовы к коммиту), а какие еще не отслеживаются.
  • git diff - показывает разницу между текущим состоянием рабочего каталога и индексом (или последним коммитом).
  • git rm <файл> - отменяет изменения в рабочем каталоге или индексе
